# Urban Fleet Operations – Vehicle Service Management

## Project Overview

Urban Fleet Operations provides vehicle servicing to individual customers
through multiple service centres. Customers currently raise service requests
through phone calls and emails, resulting in delays, limited visibility,
and inefficient tracking of service history.

This Pega application provides a centralized vehicle service management
solution that allows customers to raise service requests and enables
service teams to manage, track, and resolve those requests efficiently.

## Problem Statement

- Service requests are raised through phone and email
- Lack of centralized request tracking
- Difficult to monitor service status
- Limited visibility into service history
- Manual assignment and follow-up
- Delays in service request processing

## Solution

The application digitizes the vehicle service request process using
Pega Platform and provides:

- Service request creation
- Customer and vehicle information management
- Service request tracking
- Service centre management
- Request assignment
- Workflow-based processing
- Status tracking
- Service history

## Case Type

### Vehicle Service Request

The Vehicle Service Request is the primary case type used to manage
the complete lifecycle of a customer's vehicle service request.

## Main Stages

1. Request Submission
2. Service Assessment
3. Service Processing
4. Quality Check
5. Service Completion

## Key Features

- Customer service request submission
- Vehicle details capture
- Service type selection

- Request status tracking
- Automated workflow
- Service history tracking

## Project Outcome

The solution improves visibility, reduces manual tracking, standardizes
the service workflow, and provides a centralized platform for managing
vehicle service requests.
